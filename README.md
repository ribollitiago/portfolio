# Portfolio

Personal developer portfolio — a responsive single-page application showcasing projects, skills, and contact information.

---

## Features

- **Multi-page SPA** — Home, About, Projects, Contact, and Budget pages
- **Responsive layout** — optimised for all screen sizes
- **Angular routing** — smooth client-side navigation with no page reloads
- **Custom branding** — SVG logo and visual assets integrated across the UI
- **Contact & Budget forms** — built-in pages for direct outreach

---

## Tech Stack

| Layer | Technology |
|---|---|
| Language | TypeScript |
| Framework | Angular 19 |
| Styling | SCSS |
| Package manager | npm |

---

## Getting Started

### Prerequisites

- Node.js 18+
- Angular CLI: `npm install -g @angular/cli`

### Install & Run

```bash
npm install
ng serve
```

Open [http://localhost:4200](http://localhost:4200) in your browser.
